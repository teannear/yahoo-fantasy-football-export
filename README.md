# Yahoo Fantasy Football Data Export

This is a personal, non-commercial project used to export and analyze my own Yahoo Fantasy Football league history through the Yahoo Fantasy Sports API.

The project is intended for read-only access only. It will not modify rosters, league settings, transactions, or any other Yahoo Fantasy data.

The exported data will be used locally to create private league analytics, record books, all-time manager standings, matchup history, rivalry records, keeper league summaries, and season recap reports.

This project is not a public consumer application and is not affiliated with Yahoo.
